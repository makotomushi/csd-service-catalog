## 01　IT構想策定・ソリューション選定支援サービス

### サービス概要

老朽化したシステムの刷新や業務システム導入を検討しているお客様に対し、業務課題の整理から要件整理、RFP作成、ベンダー選定までを一貫して支援します。

> 💬 「システムを新しくしたいが、何から始めればよいかわからない」  
> 💬 「ERPやパッケージを導入したいが、自社に最適な製品がわからない」

このような課題に対して、事業部門と対話しながら最適な方向性を整理し、導入パートナー選定までを伴走します。

## 02　IT投資判断支援サービス

### サービス概要

IT投資に対する費用対効果、リスク、実現性を整理し、経営層や事業部門が納得できる投資判断材料を提供します。

> 💬 「システム刷新は必要だが、本当に投資すべきか判断できない」  
> 💬 「ERPとモダナイゼーション、どちらが自社に最適か判断できない」  
> 💬 「経営層へ説明できる資料が作れない」

複数の選択肢を比較評価し、最適な意思決定を支援します。

---

| 項目 | 内容 |
|------|------|
| **期間目安** | 1ヶ月〜3ヶ月 |
| **体制** | PM 1名 ＋ メンバー 1名（計2名） |
| **概算工数** | 2人月〜6人月 |
| **概算金額** | **240万円〜720万円**（税抜） |
| **単価前提** | 120万円／人月 |

#### フェーズ別 概算工数イメージ

| フェーズ | 期間目安 | 工数目安 | 概算金額 |
|---------|---------|---------|---------|
| 現状分析 | 0.25〜0.5ヶ月 | 0.5〜1人月 | 60万〜120万円 |
